# PulseBoard – React Admin Dashboard

A modern, responsive SaaS-style Admin Dashboard built with React and Vite.

## 🚀 Live Demo

https://pulseboard-react-dashboard-27ij.vercel.app

## 📂 GitHub Repository

https://github.com/Raistar2005/pulseboard-react-dashboard

## ✨ Features

- Responsive Sidebar
- Top Navigation
- Dashboard Statistics Cards
- Revenue Overview
- Recent Orders Table
- User Profile Card
- Activity Panel
- Notifications
- Search and Order Filtering
- Responsive Mobile Layout
- Light UI Animations
- Reusable React Components

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React Icons
- React Hooks

## ⚙️ Installation

Clone the repository:

git clone https://github.com/Raistar2005/pulseboard-react-dashboard.git

Navigate into the project:

cd pulseboard-react-dashboard

Install dependencies:

npm install

Run the development server:

npm run dev

## 🏗️ Production Build

npm run build
